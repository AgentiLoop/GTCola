# GTCola

🤖 **Built by the makers of [Agent!](https://github.com/AgentiLoop/Agent)**, an autonomous macOS agent. 🌐 [agentiloop.ai](https://agentiloop.ai)

A mysterious name for Apple AirPlay 1, 2 and native volume control on iOS used in StarplayrX, a third party SiriusXM Radio player. This does not work on Simulator or macOS. Uses Apple's native volume rocker with the ability to use a custom volume slider.  Works in the iOS AppStore. Objective-C strings are encrypted twice.
